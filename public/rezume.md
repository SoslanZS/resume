## Оптимизация производительности (ключевой навык)

- Работа с метриками **PageSpeed / Core Web Vitals**: LCP, CLS, TBT.
- Отложенная загрузка аналитики и тяжёлых скриптов (Яндекс.Метрика, Sentry, карты, виджеты) до первого взаимодействия пользователя или до попадания блока в зону видимости.
- Оптимизация шрифтов: сабсеттинг под нужные алфавиты, перевод в woff2, font-metric fallback, preload критичных ресурсов, удаление неиспользуемых начертаний.
- Оптимизация изображений: перевод в webp, lazy-load, `<picture>` с адаптивными источниками, резервирование места под контент для устранения CLS.
- Оптимизация бандла: разбиение на чанки, ленивая гидрация блоков ниже первого экрана, code-splitting CSS, вынос сторонних библиотек из основного бандла.
- Локализация внешних библиотек, удаление мёртвого кода и legacy-слоёв (jQuery, Bootstrap, поддержка IE).

## Основные проекты (ведущий / единственный фронтенд-разработчик)

### lineaflex — интернет-магазин матрасов и товаров для сна
Nuxt, Bitrix. **Разработал сайт с нуля.**
- Навигация, баннеры, приветственный блок, блоки технологий (Flex&Roll, Twin&Roll, Perfect Side), блок материалов, блок «истории».
- Корзина с пересчётом цены, фильтры каталога, формы (в т.ч. форма для дизайнеров), попапы.
- SEO: микроразметка карточки товара, канонические URL, нормализация адресов и защита от дублей посадочных страниц.
- Оптимизация: webp, lazy-load, асинхронная загрузка скриптов, удаление лишних зависимостей и шрифтов, зум изображения на детальной.

### zvet — крупный интернет-магазин зоотоваров
Bitrix, Gulp / SCSS / jQuery, частичная миграция на Vue. **Ведущий разработчик на поддержке и развитии.**
- Новые функции: колесо фортуны и callback-попапы, интеграция Choosify, переработанные слайдеры (Slick / Swiper), доработки корзины, выбор города с сохранением в cookie.
- **Оптимизация детальной и главной страниц по PageSpeed:** запуск слайдеров по факту видимости, вынос вызова метрик на пользовательские события, отложенная загрузка iframe-видео, миграция CSS-библиотек и компонентных стилей.
- Постоянное исправление багов по всему сайту (каталог, детальная, оформление заказа, смена города и цвета товара).

### front (seneca) — B2B и розничный интернет-магазин
Nuxt 4, Vue, Pinia, SASS, Swiper, Playwright.
- OAuth-вход через VK и Яндекс, верификация по звонку.
- Доработка оформления заказа: пересчёт цены при смене курьерской компании, корректная обработка опустевшей корзины, порядок чтения ответа платёжной системы до навигации.
- Восстановление событий Enhanced Ecommerce для Яндекс.Метрики, точечная передача пропсов бейджей в карточки товара.
- **Большой объём работ по производительности:** сабсеттинг шрифта Inter (latin + cyrillic, woff2, preload под LCP), отложенная загрузка Метрики и карт, webp для фоновых изображений, ленивая гидрация, разбиение попапов на чанки, отказ от лишних MutationObserver в пользу нативного `:has()`.
- Написание e2e-тестов на Playwright для розницы и Pro-раздела, уведомление о результатах прогона в Telegram.

### avicenna — сайт медицинской клиники
Nuxt 3, Vue 3, Swiper, Regle.
- Онлайн-запись через модальное окно Medflex вместо popup-виджета, маппинг ID врачей и услуг, кросс-фильтрация селектов врача и услуги.
- Переработка формы записи на Regle и общий ui-kit, маска телефона, устойчивость списков к частичным ошибкам API.
- Удаление legacy Bootstrap / jQuery и переработка вёрстки по ТЗ клиента.
- Яндекс.Метрика со SPA-трекингом маршрутов, блоки FAQ / преимущества / облако тегов, раздельный вывод цен услуги и консультации.
- Исправление 500-ошибок (пустой информационный блок в баннере), багов скролла в попапах и мобильного меню, lazy-load медиа ниже первого экрана.

### hukali-village — лендинг
Nuxt 3, SASS.
- Свёрстал и внедрил главную страницу лендинга, интеграция виджета bnova, ссылки на мессенджеры.
